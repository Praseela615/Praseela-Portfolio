A professional, responsive portfolio website for an MCA student and aspiring software developer.

- Modern recruiter-focused design
- Responsive desktop/tablet/mobile layout
- Hero, About, Skills, Projects, Education, Engineering Direction and Contact sections
- Resume download button

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on GitHub Pages
1. Create a repository named `praseela-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md` and your `resume.pdf`.
3. Open Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save and wait for GitHub Pages to publish.

## Customize before publishing
- Replace `your-email@example.com` in `index.html`.
- Replace the LinkedIn placeholder with your profile URL.
- Add your real `resume.pdf` to the root folder.
- Add a professional profile photo later if desired.

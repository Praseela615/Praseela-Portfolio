# Praseela S. Tamse — New Portfolio

A completely redesigned personal portfolio built from scratch with a distinct visual identity.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- LocalStorage for theme preference

## Features
- Premium dark/light mode design
- Responsive mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Project showcase
- Education and experience timeline
- Resume download
- Contact section
- Mobile-friendly layout

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages deployment
1. Create a new GitHub repository.
2. Upload all project files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/root`.
6. Save and wait for the Pages URL.

## Note about contact form
This version validates the form and shows a confirmation message but does not send email to a server. For real submissions on GitHub Pages, connect the form to a service such as Formspree.
